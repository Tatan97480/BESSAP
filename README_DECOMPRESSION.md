# Installation rapide

## iPhone / iPad
1. Télécharge `BE_STRONGER_V22.zip`.
2. Ouvre **Fichiers**.
3. Va dans **Téléchargements**.
4. Touche le fichier ZIP : iOS le décompresse automatiquement dans un dossier.
5. Ouvre le dossier et utilise les fichiers du projet.

## Mac / PC
Double-clique simplement sur le ZIP pour le décompresser.

Le ZIP est volontairement standard et sans mot de passe pour faciliter l'installation.
