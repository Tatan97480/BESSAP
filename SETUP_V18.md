# BE STRONGER V22

V22 ajoute le mode **Séance Live** et un vrai socle de suivi de performance.

## Nouveautés
- Séance guidée en temps réel
- chronomètre par exercice
- checklist série par série
- charge / RPE / notes
- validation de séance
- proposition automatique de charge suivante
- centre de suivi coach
- tables Supabase de session logs / set logs / métriques / notifications
- fonction serveur de suggestion de progression

## Installation
1. V15 puis V16 puis V22 restent nécessaires si tu pars d'un projet neuf.
2. Exécuter `supabase_v18_additions.sql`.
3. Renseigner `config.js`.
4. Publier.

## Prochaine étape production
Connecter le mode Live aux tables Supabase, synchroniser les données en temps réel, ajouter les notifications push, les vidéos hébergées et un vrai système de progression par exercice.
